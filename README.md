# 🤖 AI-ГДЗ Telegram Bot

Умный Telegram-бот, который не просто дает готовые ответы на домашние задания, а помогает их понять с помощью искусственного интеллекта. 

---

## ✨ Возможности

<!-- * 📚 **Поиск по готовым домашним заданиям:** Быстрый доступ к базе ответов для разных классов и предметов. -->
* 🧠 **ИИ-помощник (ChatGPT / YandexGPT и др.):** Объясняет сложные темы, разбирает формулы и правила простым языком.
* 📸 **Распознавание заданий:** Возможность отправить фото страницы учебника или условия задачи.
* ⏱ **Экономия времени:** Помогает быстро проверить себя перед сдачей домашки.

---

## 🛠 Технологии

* **Язык:** Python 3.x 
* **Фреймворк:** aiogram / telebot
* **ИИ-модель:** OpenAI API / Anthropic / Gemini
* **База данных:** PostgreSQL / SQLite / MongoDB
